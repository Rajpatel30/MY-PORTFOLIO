## How to Deploy on GitHub Pages
1. Create a new repository on GitHub (for example: `raj-patel-portfolio` or `yourusername.github.io`).
2. Push these files to the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. Go to **Repository Settings → Pages → Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `(root)`
   - Click **Save**.
4. Your live site will be available at `https://<your-username>.github.io/<repo-name>/` within 1–2 minutes.'''
