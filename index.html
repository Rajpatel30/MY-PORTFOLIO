03 / Featured Work

Project

Deep Learning · Medical Imaging ViT-Base/16 + Grad-CAM

Brain Tumor MRI Classifier using Vision Transformer (ViT)

An end-to-end medical image classification and explainability system built to classify brain MRI scans into four clinical categories—Glioma, Meningioma, Pituitary, and No Tumor—using the Kaggle MRI dataset.

  • Transfer Learning with ViT-Base/16: Fine-tuned Google's ViT-Base/16 architecture via PyTorch and HuggingFace Transformers for multi-class MRI classification.
  • Training Optimization: Addressed dataset class imbalance and applied two-phase fine-tuning with mixed-precision training for faster, stable convergence.
  • Explainable AI (Grad-CAM): Integrated Grad-CAM heatmaps with OpenCV to highlight the exact spatial regions influencing each prediction.
  • Interactive Streamlit App: Built a clean web interface displaying the predicted class, confidence score, and top-4 class probability breakdown.
